# FullControl Workshop

## Setup (first time only)

**Windows:** Double-click `setup_windows.bat`  
**Mac/Linux:** Run `./setup_mac.sh`

## Run the workshop

**Windows:** Double-click `run_windows.bat`  
**Mac/Linux:** Run `./run_mac.sh`

Opens in your browser.

## Troubleshooting

**Setup fails?** Check internet connection and try again.

**"Permission denied" (Mac/Linux)?** Run: `chmod +x setup_mac.sh run_mac.sh`

**Need to reset?** Delete the `Miniconda3` folder and run setup again.
